# UBORA Makerspace Training

This repository is used to share teaching and learning materials for the UBORA Makerspace teacher training program.

It will contain materials from our training sessions, including:

* Lesson notes and presentations
* Programming exercises and examples
* Micro:bit and Arduino projects
* Robotics and electronics resources
* 3D modelling and makerspace activities
* Projects and files created by the teachers
* Other useful resources shared during the training

### How to use this repository

**For teachers**

* Upload your projects, exercises, and other files from the training.
* Check the repository regularly for new materials.
* Feel free to use and adapt the materials for your own classes and STEM activities.

The repository will continue to grow throughout the training, so keep checking back for new materials.

## Repository overview so far

### 1. Python fundamentals

The `000_PYTHON` section includes starter lessons and practice activities focused on Python programming basics.

### 2. Micro:bit and MicroPython

The `001_MICROBIT-MICROPYTHON` section is dedicated to Micro:bit programming and MicroPython-based activities.

### 3. Arduino and electronics

The `002_ARDUINO` section includes:

- lesson notes for Arduino basics
- LED and button projects
- PWM and sensor activities
- circuit diagrams and sample code
- example sketches for practical experimentation

### 4. Assignments and student work

The `Assignments/` folder contains course-related tasks and examples created for the learning program.

### 5. Student and teacher code samples

The `codes/` folder includes work from different learners and groups, such as:

- Python exercises
- Arduino sketches
- Micro:bit scripts
- conditionals, functions, loops, and input/output examples

## Main folders

- `000_PYTHON/` - Python lessons and activities
- `001_MICROBIT-MICROPYTHON/` - Micro:bit and MicroPython content
- `002_ARDUINO/` - Arduino lesson files and sample projects
- `Assignments/` - course assignments and tasks
- `codes/` - example code and learner projects

## Suggested use

- Start with the Python materials for fundamental programming concepts.
- Move to Micro:bit activities for embedded programming concepts.
- Use Arduino lessons to explore electronics, sensors, and control systems.
- Review the `codes/` folder for practical examples and implementation patterns.

## Learning goals

This repository supports learning in:

- programming logic
- Python syntax and structure
- loops, conditions, and functions
- electronics and circuit basics
- Arduino project development
- embedded systems and physical computing

## Notes

The materials in this repository are intended for educational use, sharing, and adaptation in STEM teaching environments. They can be used as classroom content, learning examples, or project references.
