# Arduino Lessons

These lessons build from digital inputs to analog sensing and PWM-controlled outputs.

## Lessons

1. [Buttons and Digital Inputs](<lesson2_(buttons).md>) - Read a button, interpret its state, and use it to control an LED.
2. [Pulse-Width Modulation](<lesson3_(Pulse_Width_Modulation).md>) - Read a potentiometer and use PWM to dim an LED.
3. [Light Sensors](<lesson4_(ldr).md>) - Use an LDR, photodiode, or phototransistor to control an LED.
