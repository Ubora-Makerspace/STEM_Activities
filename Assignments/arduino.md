# End-of-Week Arduino Project Challenge

## Overview

This week, we are moving into **Arduino, sensors, and physical prototyping**.

Your challenge is to build a small working project that uses an **Arduino and at least one sensor** to solve a simple real-world problem.

The goal is not to build something complicated. Focus on understanding how the sensor works, writing the program, connecting the components correctly, and demonstrating a useful response from your system.

## Project Requirements

Your project must:

* Use an **Arduino** as the main controller.
* Use **at least one sensor** from the Arduino sensor kit.
* Read information from the sensor in your program.
* Make the Arduino respond to the sensor reading.
* Include a physical circuit using appropriate connections and a breadboard where necessary.
* Be demonstrated at the end of the week.

### CAD Integration: Nice to Have

Adding a **CAD-designed component** is encouraged but **not required** this week.

For example, you could design:

* A case for your electronics
* A sensor holder
* A robot chassis
* A protective cover
* A mounting bracket
* A small enclosure
* A wheel or mechanical component

The CAD component can be designed for 3D printing or simply used to demonstrate how your physical design could be improved.

## Project Ideas

You may choose one of these ideas or come up with your own.

### 1. Soil Moisture Detector

Build a system that detects whether soil is dry or wet.

**Possible features:**

* Soil moisture sensor
* LED indicating the soil condition
* Buzzer when the soil becomes too dry
* Servo or small pump simulation for watering

**Optional CAD:** Design a small enclosure or sensor holder.


### 2. Automatic Plant Watering System

Build on the soil moisture detector by creating a system that automatically responds when the soil becomes dry.

**Possible features:**

* Soil moisture sensor
* Water pump or servo
* LED status indicator
* Automatic watering based on a threshold

**Optional CAD:** Design a plant pot attachment or sensor/pump holder.


### 3. Autonomous Obstacle-Avoiding Robot

Build a small robot that can detect obstacles and change direction automatically.

**Possible features:**

* Ultrasonic distance sensor
* Two or more motors
* Motor driver
* Arduino
* LEDs or buzzer for status

**Optional CAD:** Design a simple robot chassis or sensor mount.


### 4. Smart Parking Sensor

Create a system that detects how close an object is to a parking position.

**Possible features:**

* Ultrasonic sensor
* LEDs showing distance
* Buzzer that becomes more frequent as an object gets closer

**Optional CAD:** Design a small parking model or sensor housing.


### 5. Automatic Night Light

Build a light that automatically turns on when the environment becomes dark.

**Possible features:**

* Light-dependent resistor (LDR)
* LED
* Automatic brightness or on/off control

**Optional CAD:** Design a lamp enclosure or diffuser.


### 6. Smart Dustbin

Build a dustbin that detects when someone approaches and opens automatically.

**Possible features:**

* Ultrasonic sensor
* Servo motor
* Arduino

**Optional CAD:** Design a lid mechanism or small dustbin model.


### 7. Temperature Monitoring System

Build a system that monitors temperature and provides a response when the temperature crosses a threshold.

**Possible features:**

* Temperature sensor
* LED indicators
* Buzzer
* LCD/OLED display if available

**Optional CAD:** Design a small enclosure for the electronics.


## Minimum Deliverable

By the end of the week, your project should have:

### Hardware

* [ ] Arduino
* [ ] At least one sensor
* [ ] Breadboard and appropriate connections
* [ ] Output component such as an LED, buzzer, servo, motor, or display

### Software

* [ ] Arduino program
* [ ] Sensor readings are used to make decisions
* [ ] The system responds automatically to the sensor

### Documentation

Create a short project README containing:

1. **Project Name**
2. **Problem Being Solved**
3. **How the System Works**
4. **Components Used**
5. **Circuit/Connection Diagram**
6. **Arduino Code**
7. **How to Use/Test It**
8. **Challenges Encountered**
9. **Possible Improvements**

### Optional CAD

If you include CAD:

* Add the CAD file or screenshots to the project.
* Explain what the component is used for.
* Explain how it improves the physical design.

## Important

The project does **not** need to be perfect or production-ready.

We are looking for evidence that you can:

**Sense → Process → Respond**

For example:

> Soil moisture sensor → Arduino reads moisture → Arduino turns on an indicator when the soil is dry.

Try to make your project something that could eventually become a useful real-world system.

## Presentation

Each teacher should be prepared to give a short demonstration showing:

1. What problem the project solves.
2. The components used.
3. How the sensor works.
4. The Arduino program.
5. The system responding to a real input.
6. Any CAD component, if included.

## Challenge

Once the basic project works, try adding **one extra feature**.

Examples:

* Add another sensor.
* Add a display.
* Add a buzzer or LED warning system.
* Add automatic control.
* Improve the physical design.
* Add a CAD-designed enclosure or mechanical component.
* Make the system respond to different sensor ranges.

**Start simple. Get the basic system working first, then build on it.**
