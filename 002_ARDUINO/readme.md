# Arduino Lessons

This section introduces students to Arduino basics, digital and analog input, output control, and sensor-based projects.

## Lesson sequence

1. [Getting Started with Arduino](<LESSON0_(Getting_started_with_Arduino).md>)  
   Learn the Arduino board, IDE, programming environment, and basic workflow.

2. [Connecting LEDs](<LESSON1(Connecting_LEDs).md>)  
   Explore how to wire and control LEDs, including basic output circuits.

3. [Buttons and Digital Inputs](LESSON2_Buttons.md)  
   Read button states and use them to change the behavior of an LED or circuit.

4. [Pulse Width Modulation](<LESSON3_(Pulse_Width_Modulation).md>)  
   Learn how PWM controls brightness and other analog-like effects.

5. [Light Dependent Resistor](LESSON4_LIGHT_DEPENDENT_RESISTOR.md)  
   Use an LDR to build a light-sensitive project and interpret sensor readings.

## Learning focus

These lessons build from simple outputs to digital inputs, analog-style control, and sensor-driven circuits. Students progress from understanding the board and LEDs to reading switches and light levels, then applying those concepts in small Arduino projects.
